# TU/e FAIR Data Clinic Toolkit

Public release repository for the TU/e FAIR Data Clinic Toolkit.

## Current public release

**v5.8.0-rc15 — Final stabilization candidate**

RC15 is a standalone browser-based proof of concept for pre-deposit Dataset Content and Reuse Readiness assessment within a combined Researcher and Data Steward workflow.

The toolkit evaluates research-data package structure, documentation, metadata, provenance, software, rights, access information, and relationships before repository deposit. It does not calculate or certify a FAIR score, does not provide institutional approval, and does not make a live repository connection.

### Release artifact

`fair-raps-researcher-toolkit_5_8_0-rc15.html`

The application is self-contained. Download the HTML file and open it in a modern browser.

SHA-256 checksums are provided in `SHA256SUMS.txt`.

## Development model

This repository contains curated public releases only. Development history, development branches, CI/Codex materials, internal validation artifacts, and unreleased development versions are maintained separately and are not part of this public repository.
